Como a IA trabalha
  1. A pergunta é ligada a um catálogo fechado de 22 ferramentas de indicadores: a IA não escreve SQL.
  2. Os números vêm da camada analítica pseudonimizada: nenhum nome ou CPF chega à IA.
  3. Os gráficos são escolhidos pela IA, mas montados pelo sistema com dados do banco.
  4. A conversa lembra as últimas 4 perguntas; os números são sempre consultados de novo.
  5. Cada consulta fica registrada para auditoria.
